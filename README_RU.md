# BL4 Super Dash

Выполняет технику Super Dash в Borderlands 4 одним переназначаемым нажатием клавиши или кнопки геймпада — теперь в текущем направлении движения.

## Возможности

- Super Dash одной кнопкой.
- Направление Super Dash определяется текущим направлением движения.
- Клавиатура поддерживает все 8 направлений, включая диагонали.
- На геймпаде сохраняется непрерывный угол левого стика, без квантования только в 4/8 направлений.
- С места сохраняется прежнее поведение: Super Dash вперёд.
- Работает во время обычного движения и спринта.
- Сохраняет спринт после приземления, если Super Dash был начат из спринта.
- Клавиши/стик движения можно физически не отпускать во время последовательности.
- Поддерживаются клавиатура/мышь и геймпад.
- Используются нативные вызовы Dash и Jump Borderlands 4.
- Нет Windows SendInput и внешних макросов.
- Есть настраиваемые параметры таймингов.
- Нет штатного спама в SDK-консоль; лог используется только для ошибок/abort-диагностики.

## Требования

- Borderlands 4
- BL-SDK / Oak2 Mod Manager
- Mods Base 1.12+
- Keybinds 1.1+
- Управление движением с клавиатуры или геймпада

## Установка

1. Скопируйте `BL4_SuperDash.sdkmod` в:

   `Borderlands 4\sdk_mods\`

2. Запустите Borderlands 4.
3. Откройте меню PythonSDK / Mods.
4. Включите **BL4 Super Dash**.
5. Назначьте **Super Dash** на нужную клавишу клавиатуры, кнопку мыши или кнопку геймпада.

Не распаковывайте `BL4_SuperDash.sdkmod`.

Перед установкой релиза удалите или отключите старые тестовые/probe-сборки SuperDash.

## Направление рывка

Версия 1.2.0 запоминает текущий вектор движения в момент нажатия Super Dash.

- Одиночные W/A/S/D сохраняют соответствующее направление.
- Сочетания W+D, S+D, S+A и W+A дают диагональный Super Dash.
- На геймпаде используется текущий непрерывный угол стика, включая промежуточные углы между обычными 8 направлениями.
- Величина отклонения стика не уменьшает силу Super Dash: используется только угол.
- Если персонаж фактически стоит на месте, рывок выполняется вперёд относительно текущего направления взгляда, как в предыдущих версиях.

Внутри BL4 нативный Dash имеет четыре направления. Мод запускает ближайшее нативное направление, после чего поворачивает только горизонтальную скорость рывка на точный захваченный угол, сохраняя вертикальную скорость и нативную скорость Dash.

## Настройка

Значения по умолчанию являются протестированными релизными настройками и обычно не требуют изменения.

- **Movement Neutral Frames:** 1
- **Jump Hold (ms):** 25
- **Jump Release -> Dash Release (ms):** 15
- **Dash Start Timeout (ms):** 300

## Сохранение спринта

Если Super Dash запускается, когда персонаж уже действительно находится в спринте, мод запоминает это состояние, выполняет последовательность Super Dash, ждёт приземления и восстанавливает штатный sprint intent игры.

Если Super Dash был начат из обычного движения, спринт принудительно не включается.

## Версия 1.2.0

- Добавлен Super Dash в текущем направлении движения.
- Добавлены диагональные направления клавиатуры.
- Добавлена поддержка непрерывного аналогового направления геймпада.
- Сохранён прежний forward-fallback с места.
- Экспериментальная коррекция через накопление `AddImpulse` заменена прямым поворотом горизонтальной velocity; это устраняет накопленные скачки скорости и рывок направления камеры, обнаруженный в первом directional-прототипе.
- Убран подробный debug/trace-вывод каждого срабатывания в SDK-консоль; успешные обычные срабатывания не пишутся в лог.
- Сохранены прежние тайминги и восстановление спринта.
