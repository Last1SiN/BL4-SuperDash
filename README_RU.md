# BL4 Super Dash

Выполняет технику Super Dash в Borderlands 4 одним переназначаемым нажатием клавиши или кнопки геймпада.

## Возможности

- Super Dash одной кнопкой.
- Работает с места.
- Работает во время движения вперёд.
- Работает во время спринта.
- Сохраняет спринт после приземления, если Super Dash был начат из спринта.
- Forward можно физически не отпускать во время всей последовательности.
- Поддерживаются клавиатура/мышь и геймпад.
- Автоматически определяются клавиатурные и геймпадные mappings движения.
- Используются нативные вызовы Dash и Jump Borderlands 4.
- Нет Windows SendInput и внешних макросов.
- Есть настраиваемые параметры таймингов.

## Требования

- Borderlands 4
- BL-SDK / Oak2 Mod Manager
- Mods Base 1.12+
- Keybinds 1.1+
- Управление движением с клавиатуры или геймпада

## Установка

1. Скопируйте `BL4_SuperDash.sdkmod` в:

   `Borderlands 4\sdk_mods\`

2. Запустите Borderlands 4.
3. Откройте меню PythonSDK / Mods.
4. Включите **BL4 Super Dash**.
5. Назначьте **Super Dash** на нужную клавишу клавиатуры, кнопку мыши или кнопку геймпада.

Не распаковывайте `BL4_SuperDash.sdkmod`.

Перед установкой релиза удалите или отключите старые тестовые сборки.

## Настройка

Значения по умолчанию являются протестированными релизными настройками и обычно не требуют изменения.

- **Forward Neutral Frames:** 1
- **Jump Hold (ms):** 25
- **Jump Release -> Dash Release (ms):** 15
- **Dash Start Timeout (ms):** 300

## Сохранение спринта

Начиная с версии 1.1.1 мод сохраняет состояние спринта при выполнении Super Dash.

Если Super Dash запускается, когда персонаж уже действительно находится в спринте, мод запоминает это состояние, выполняет обычную последовательность Super Dash, ждёт приземления и восстанавливает штатное sprint intent игры.

Если Super Dash был начат из обычного движения, спринт принудительно не включается.
