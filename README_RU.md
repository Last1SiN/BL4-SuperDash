# BL4 Super Dash

BL4 Super Dash превращает технику Super Dash в одно нажатие.

Нажимаешь назначенную кнопку — мод выполняет последовательность в том направлении, куда персонаж уже движется. На клавиатуре поддерживаются все восемь направлений, включая диагонали, а на геймпаде используется реальный угол стика без привязки к фиксированным секторам.

Есть и отдельный необязательный биндинг обычного Dash для быстрых рывков вперёд и по диагонали. Внешние макросы и эмуляция клавиш не используются.

## Возможности

- Super Dash одной кнопкой.
- Рывок идёт в текущем направлении движения.
- Все восемь направлений на клавиатуре, включая диагонали.
- На геймпаде используется реальный угол левого стика.
- Если персонаж стоит, Super Dash выполняется вперёд.
- Работает и из обычного движения, и из спринта.
- После приземления восстанавливает спринт, если он был активен до рывка.
- Клавиши или стик движения не нужно отпускать во время последовательности.
- Есть отдельный необязательный биндинг обычного Dash.
- Используются штатные действия Dash и Jump Borderlands 4, без внешних макросов.

## Требования

- Borderlands 4.
- [BL4 PythonSDK / Oak2 Mod Manager v0.3+ — актуальный стабильный релиз](https://github.com/bl-sdk/oak2-mod-manager/releases/latest).
- [Официальная инструкция по установке BL4 SDK](https://bl-sdk.github.io/oak2-mod-db/).

Oak2 Mod Manager v0.3 уже включает необходимые **Mods Base 1.12**, **Console Mod Menu 1.6** и **Keybinds 1.1**. При использовании этого релиза или более новой совместимой версии Oak2 отдельно скачивать эти компоненты не нужно.

## Установка

1. **Полностью закройте Borderlands 4.**
2. Если BL4 PythonSDK / Oak2 ещё не установлен или его нужно обновить, скачайте [актуальный стабильный релиз Oak2 Mod Manager](https://github.com/bl-sdk/oak2-mod-manager/releases/latest). Распакуйте содержимое релиза SDK непосредственно в **корневую папку Borderlands 4** — ту, где находится папка `OakGame` — с объединением папок и файлов. Полная процедура, включая примечания для Proton/Linux, находится в [официальной инструкции BL4 SDK](https://bl-sdk.github.io/oak2-mod-db/).
3. После установки/обновления SDK один раз запустите Borderlands 4. Дважды нажмите `~`, чтобы открыть SDK-консоль, введите `mods` и убедитесь, что открывается Mod Menu.
4. Скачайте актуальный **BL4 Super Dash** из [GitHub Releases](https://github.com/Last1SiN/BL4-SuperDash/releases/latest) или с [Nexus Mods](https://www.nexusmods.com/borderlands4/mods/289).
5. Снова полностью закройте игру и скопируйте `BL4_SuperDash.sdkmod` **не распаковывая** в:

   `Borderlands 4\sdk_mods\`

6. Запустите/перезапустите Borderlands 4. Дважды нажмите `~`, введите `mods`, откройте **BL4 Super Dash** и включите мод.
7. В настройках мода назначьте **Super Dash** на нужную клавишу клавиатуры, кнопку мыши или кнопку геймпада.

Для обновления BL4 Super Dash замените существующий `BL4_SuperDash.sdkmod` более новой версией файла и перезапустите игру.

## Направление рывка

Версия 1.2.0 запоминает текущий вектор движения в момент нажатия Super Dash.

- Одиночные W/A/S/D сохраняют соответствующее направление.
- Сочетания W+D, S+D, S+A и W+A дают диагональный Super Dash.
- На геймпаде используется текущий непрерывный угол стика, включая промежуточные углы между обычными 8 направлениями.
- Величина отклонения стика не уменьшает силу Super Dash: используется только угол.
- Если персонаж фактически стоит на месте, рывок выполняется вперёд относительно текущего направления взгляда.

Внутри BL4 нативный Dash имеет четыре направления. Мод запускает ближайшее нативное направление, после чего поворачивает только горизонтальную скорость рывка на точный захваченный угол, сохраняя вертикальную скорость и нативную скорость Dash.

## Настройка

Значения по умолчанию являются протестированными релизными настройками и обычно не требуют изменения.

- **Movement Neutral Frames:** 1
- **Jump Hold (ms):** 25
- **Jump Release -> Dash Release (ms):** 15
- **Dash Start Timeout (ms):** 300

## Сохранение спринта

Если Super Dash запускается, когда персонаж уже действительно находится в спринте, мод запоминает это состояние, выполняет последовательность Super Dash, ждёт приземления и восстанавливает штатный sprint intent игры.

Если Super Dash был начат из обычного движения, спринт принудительно не включается.

## Версия 1.2.0

- Добавлен Super Dash в текущем направлении движения.
- Добавлены диагональные направления клавиатуры.
- Добавлена поддержка непрерывного аналогового направления геймпада.
- Сохранён прежний forward-fallback с места.
- Экспериментальная коррекция через накопление `AddImpulse` заменена прямым поворотом горизонтальной velocity; это устраняет накопленные скачки скорости и рывок направления камеры, обнаруженный в первом directional-прототипе.
- Убран подробный debug/trace-вывод каждого срабатывания в SDK-консоль; успешные обычные срабатывания не пишутся в лог.
- Сохранены прежние тайминги и восстановление спринта.
